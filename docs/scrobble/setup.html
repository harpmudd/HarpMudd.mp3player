Scrobble setup

Getting your own Last.fm API key — about two minutes, once

Why your own key

Scrobbling has to be signed with a Last.fm secret. The scrobble page has no server behind it — it is a single file on GitHub Pages — so anything built into it is readable by anyone who opens it.

Shipping one shared secret would mean everybody's scrobbling stops the day somebody abuses it. A key of your own costs one signup, is stored only in your own browser, and cannot affect anyone else. Your Last.fm password is never involved either way.

Steps

  1. Sign in to Last.fm, then open the API account form. last.fm/api/account/create
  2. Fill it in. Only the callback matters; the rest is free text and nobody reviews it.
    Application name
    Anything — for example Pocket MP3 Player.
    Application description
    Anything, e.g. “scrobbles from my Analogue Pocket”.
    Application homepage
    Optional. will do.
    Callback URL
    This one must be exact. Paste:
  3. Submit, and copy what it gives you. You get an API key and a shared secret, each 32 characters of hex. Both are needed. If you lose them they are always visible again at last.fm/api/accounts.
  4. Paste them into the scrobble page. Open it, and the setup boxes appear at the bottom. Paste the key and the secret, press Save.
  5. Press Connect Last.fm and approve. Last.fm asks once whether this application may scrobble for you. You come back to the page signed in. Nothing is submitted until you press Submit.

If something goes wrong

“Invalid method signature supplied”
Almost always the key and the secret swapped into the wrong boxes, or one of them copied short. Press Change API key and re-paste both.
“Unauthorized Token” or it never comes back signed in
The Callback URL on your API account does not match the page. It has to be exactly , trailing slash and all.
It asks for the key again later
The key lives in your browser's storage for this site. A private window, or clearing site data, loses it — and so does opening the page in a different browser. Your scrobbles are already on Last.fm; only the setup is local.
A play is missing
The Pocket only logs a track once you have heard half of it, or four minutes, whichever comes first, and never a track under 30 seconds. Those are Last.fm's own rules, not ours. A code also carries about 23 plays at most — if the session was longer, the page says so and the oldest are left out.

What gets sent

Only the track title, artist and timestamp of plays you press Submit on, and only to Last.fm.

The session travels inside the fragment of the scanned link — the part after #, which browsers never send to the server. GitHub serves the page and never sees your listening. There is no analytics on this page and no third-party script.
