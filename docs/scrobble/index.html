Open this page by scanning the code on your Pocket: play some music, then hold both triggers.

Each code holds about 16 plays. A longer session is split across several — the caption shows which one you are looking at, and Left and Right move between them. Scanning does not clear anything; the Pocket keeps the session until it is powered off.
